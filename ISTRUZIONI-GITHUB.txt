    -> vedi GUIDA-IA.md (sezione Varianti)


TRASFERIRE SU RENDER (via GitHub):

  1. Crea un repository su github.com
  2. Carica TUTTI i file di questo pacchetto (root del repo)
  3. Vai su render.com -> New -> Blueprint
  4. Collega il repository: Render legge render.yaml
     e crea il Web Service automaticamente.

  Dettagli: DEPLOY-RENDER.md


STRUTTURA DEL PROGETTO:

  client/            Frontend React + Vite + Tailwind
  server/            Server Express (serving statico)
  shared/            Costanti condivise
  cornice-dinamica/  Embed Blogger (dedicata, lite, universale,
                     autosufficiente)
  render.yaml        Blueprint Render
  .github/workflows/ CI (build automatica)
